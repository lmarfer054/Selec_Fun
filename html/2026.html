Junio. Ejercicio 1

Una ventana tiene forma de rectángulo y está coronada por un semicírculo. Sabiendo que el perímetro de la ventana mide \(8\) metros, halla las dimensiones de la ventana que permitan la mayor entrada de luz.

Planteamiento geométrico y optimización del área

Para que entre la mayor cantidad de luz posible debemos maximizar el área total de la ventana. Llamemos \(r > 0\) al radio del semicírculo superior (en metros) y \(h > 0\) a la altura de la parte rectangular. Entonces la anchura (base) del rectángulo coincide con el diámetro del semicírculo: \(b = 2r\).

1. Relación entre las variables a partir del perímetro

El perímetro exterior de la ventana está formado por la base \(2r\), los dos lados verticales \(2h\) y la semicircunferencia superior \(\pi r\):

\[2r + 2h + \pi r = 8 \implies 2h = 8 - (2 + \pi)r \implies h = \frac{8 - (2 + \pi)r}{2}\]

Para que tanto \(r\) como \(h\) sean estrictamente positivos, el dominio de validez es \(r \in \left(0,\ \dfrac{8}{2 + \pi}\right) \approx (0,\ 1{,}56)\).

2. Función área en términos de una sola variable \(\boldsymbol{r}\)

El área total es la suma del área del rectángulo (\(2rh\)) y la del semicírculo (\(\frac{1}{2}\pi r^2\)). Sustituyendo \(2h = 8 - (2 + \pi)r\):

\[A(r) = r\big(8 - (2 + \pi)r\big) + \frac{\pi}{2}r^2 = 8r - 2r^2 - \pi r^2 + \frac{\pi}{2}r^2 = 8r - \frac{4 + \pi}{2}r^2\]

3. Calculamos el máximo mediante derivadas

Derivamos \(A(r)\) e igualamos a cero:

\[A'(r) = 8 - (4 + \pi)r = 0 \implies r = \frac{8}{4 + \pi} \approx 1{,}12\text{ m}\]

Comprobamos que \(r = \dfrac{8}{4 + \pi}\) pertenece al dominio \(\left(0,\ \dfrac{8}{2 + \pi}\right)\) y verificamos con la segunda derivada que se trata de un máximo:

\[A''(r) = -(4 + \pi) < 0 \implies \text{en } r = \frac{8}{4 + \pi} \text{ se alcanza el máximo absoluto}\]

Calculamos el resto de las dimensiones óptimas:

  • Anchura de la ventana (base del rectángulo): \(b = 2r = \dfrac{16}{4 + \pi} \approx 2{,}24\text{ m}\).

  • Altura de la parte rectangular: \[h = \frac{8 - (2 + \pi)\dfrac{8}{4 + \pi}}{2} = 4\left(1 - \frac{2 + \pi}{4 + \pi}\right) = 4 \cdot \frac{2}{4 + \pi} = \frac{8}{4 + \pi} \approx 1{,}12\text{ m}\]

  • Observación: la altura del rectángulo coincide exactamente con el radio del semicírculo (\(h = r\)), de modo que la altura total de la ventana es \(h + r = \dfrac{16}{4 + \pi} \approx 2{,}24\text{ m}\), igual a su anchura.

Solución final: La entrada de luz es máxima con radio \(r = \dfrac{8}{4 + \pi} \approx 1{,}12\text{ m}\), anchura del rectángulo \(2r = \dfrac{16}{4 + \pi} \approx 2{,}24\text{ m}\) y altura del rectángulo \(h = \dfrac{8}{4 + \pi} \approx 1{,}12\text{ m}\).

Julio. Ejercicio 2

Se sabe que la función \(f : \mathbb{R} \to \mathbb{R}\) definida por \(f(x) = x^3 + ax^2 + bx + c\) verifica que: \(f(1) = 0\), \(x = 0\) es un punto crítico de la función y la recta tangente a su gráfica en \(x = -1\) es paralela a la recta de ecuación \(y + 3x = 0\). Calcula \(a\), \(b\) y \(c\).

Traducción de las condiciones y cálculo de \(a\), \(b\) y \(c\)

Al tratarse de una función polinómica, \(f\) es derivable en todo \(\mathbb{R}\) y su primera derivada es:

\[ f'(x) = 3x^2 + 2ax + b \]

1. Planteamos las tres ecuaciones a partir de los datos

  • Condición \(\boldsymbol{f(1) = 0}\): \[ 1^3 + a(1)^2 + b(1) + c = 0 \implies a + b + c = -1 \]

  • Punto crítico en \(\boldsymbol{x = 0}\): la primera derivada debe anularse en \(x = 0\): \[ f'(0) = 0 \implies 3(0)^2 + 2a(0) + b = 0 \implies \mathbf{b = 0} \]

  • Tangente en \(\boldsymbol{x = -1}\) paralela a \(\boldsymbol{y + 3x = 0}\): despejando \(y = -3x\), vemos que la pendiente de esta recta es \(m = -3\). Como dos rectas paralelas tienen la misma pendiente: \[ f'(-1) = -3 \implies 3(-1)^2 + 2a(-1) + b = -3 \implies 3 - 2a + b = -3 \implies -2a + b = -6 \]

2. Resolvemos el sistema

Ya conocemos \(\boldsymbol{b = 0}\). Sustituyendo en la tercera ecuación:

\[ -2a + 0 = -6 \implies \mathbf{a = 3} \]

Sustituyendo \(a = 3\) y \(b = 0\) en la primera ecuación:

\[ 3 + 0 + c = -1 \implies \mathbf{c = -4} \]

La función resultante es \(f(x) = x^3 + 3x^2 - 4\).

Solución final: Los coeficientes son \(a = 3\), \(b = 0\) y \(c = -4\) (es decir, \(f(x) = x^3 + 3x^2 - 4\)).
