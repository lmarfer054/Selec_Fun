Junio. Ejercicio 2

Sabiendo que

\[\lim_{x \to 0} \frac{\operatorname{sen}(x) - ax + 2 - 2\cos(x)}{e^x - x\cos(x) - 1}\]

es finito, calcula \(a\) y el valor del límite.

Cálculo del parámetro \(a\) y del valor del límite

1. Comprobamos la indeterminación inicial y aplicamos L'Hôpital por primera vez

Al sustituir \(x = 0\):

  • Numerador: \(\operatorname{sen}(0) - 0 + 2 - 2\cos(0) = 2 - 2 = 0\).

  • Denominador: \(e^0 - 0 \cdot \cos(0) - 1 = 1 - 1 = 0\).

Como obtenemos \(\left[\frac{0}{0}\right]\), derivamos numerador y denominador (cuidando la regla del producto en \(-x\cos(x)\)):

\[\lim_{x \to 0} \frac{\operatorname{sen}(x) - ax + 2 - 2\cos(x)}{e^x - x\cos(x) - 1} \stackrel{\text{L'H}}{=} \lim_{x \to 0} \frac{\cos(x) - a + 2\operatorname{sen}(x)}{e^x - \cos(x) + x\operatorname{sen}(x)}\]

2. Imponemos que el límite sea finito para hallar \(\boldsymbol{a}\)

Evaluamos el nuevo cociente en \(x = 0\):

  • Denominador: \(e^0 - \cos(0) + 0 = 1 - 1 = 0\).

  • Numerador: \(\cos(0) - a + 0 = 1 - a\).

Si \(1 - a \neq 0\), el cociente tendería a \(\pm\infty\), contradiciendo que el límite es finito. Por tanto, debe anularse el numerador: \(1 - a = 0 \implies \mathbf{a = 1}\).

3. Aplicamos L'Hôpital por segunda vez para obtener el valor del límite

Con \(a = 1\) volvemos a tener una indeterminación \(\left[\frac{0}{0}\right]\), así que derivamos una vez más:

\[\lim_{x \to 0} \frac{\cos(x) - 1 + 2\operatorname{sen}(x)}{e^x - \cos(x) + x\operatorname{sen}(x)} \stackrel{\text{L'H}}{=} \lim_{x \to 0} \frac{-\operatorname{sen}(x) + 2\cos(x)}{e^x + \operatorname{sen}(x) + \operatorname{sen}(x) + x\cos(x)}\]

Sustituimos \(x = 0\):

\[L = \frac{-0 + 2(1)}{e^0 + 0 + 0 + 0} = \frac{2}{1} = \mathbf{2}\]

Comportamiento de la función \(g(x)\) en un entorno de \(x = 0\) para \(a = 1\): el límite existe y vale \(2\).

Solución final: El parámetro es \(a = 1\) y el valor del límite es \(2\).

Junio. Ejercicio 3

Sea la función \(f : (0, +\infty) \to \mathbb{R}\) definida por \(f(x) = a + \dfrac{\ln(x)}{x^2}\).

a) Calcula \(a\) para que \(y = 1\) sea una asíntota horizontal de la gráfica de \(f\).

b) Para \(a = 0\), calcula los intervalos de crecimiento y de decrecimiento de \(f\). Estudia y halla los extremos relativos de \(f\) (abscisas donde se obtienen y valores que se alcanzan).

a) Cálculo de \(a\) para que \(y = 1\) sea asíntota horizontal

Como el dominio es \((0, +\infty)\), solo podemos estudiar la asíntota horizontal cuando \(x \to +\infty\).

Separamos la constante \(a\) y aplicamos L'Hôpital al cociente \(\dfrac{\ln(x)}{x^2}\), que es una indeterminación \(\left[\dfrac{\infty}{\infty}\right]\):

\[ \lim_{x \to +\infty} \left(a + \dfrac{\ln(x)}{x^2}\right) = a + \lim_{x \to +\infty} \dfrac{\ln(x)}{x^2} \stackrel{\text{L'H}}{=} a + \lim_{x \to +\infty} \dfrac{\dfrac{1}{x}}{2x} = a + \lim_{x \to +\infty} \dfrac{1}{2x^2} = a + 0 = a \]

La recta \(y = a\) es asíntota horizontal de \(f\) en \(+\infty\). Para que coincida con \(y = 1\), debe cumplirse \(\boldsymbol{a = 1}\).

Conclusión apartado a): La recta \(y = 1\) es asíntota horizontal para \(a = 1\).

b) Monotonía y extremos relativos para \(a = 0\)

Para \(a = 0\), trabajamos con \(f(x) = \dfrac{\ln(x)}{x^2}\), que es continua y derivable en todo \((0, +\infty)\).

1. Calculamos \(\boldsymbol{f'(x)}\) y sus puntos críticos

\[ f'(x) = \dfrac{\dfrac{1}{x} \cdot x^2 - \ln(x) \cdot 2x}{(x^2)^2} = \dfrac{x\big(1 - 2\ln(x)\big)}{x^4} = \dfrac{1 - 2\ln(x)}{x^3} \]

Igualamos a cero (el denominador \(x^3\) es siempre positivo en \((0, +\infty)\)):

\[ 1 - 2\ln(x) = 0 \implies \ln(x) = \dfrac{1}{2} \implies x = e^{1/2} = \sqrt{e} \approx 1{,}65 \]

2. Estudiamos el signo de \(\boldsymbol{f'(x)}\) y hallamos los extremos relativos

  • En \((0, \sqrt{e})\): tomamos \(x = 1 \implies f'(1) = \dfrac{1 - 0}{1} = 1 > 0 \implies\) estrictamente creciente.
  • En \((\sqrt{e}, +\infty)\): tomamos \(x = e \implies f'(e) = \dfrac{1 - 2}{e^3} = -\dfrac{1}{e^3} < 0 \implies\) estrictamente decreciente.

Al cambiar de creciente a decreciente en \(x = \sqrt{e}\), la función alcanza un máximo relativo (que además es máximo absoluto) con valor:

\[ f(\sqrt{e}) = \dfrac{\ln(e^{1/2})}{(\sqrt{e})^2} = \dfrac{1/2}{e} = \dfrac{1}{2e} \approx 0{,}184 \]

Conclusión apartado b): Creciente en \((0, \sqrt{e})\), decreciente en \((\sqrt{e}, +\infty)\). Único extremo relativo: máximo relativo en \(x = \sqrt{e}\) con valor \(f(\sqrt{e}) = \dfrac{1}{2e}\).

Julio. Ejercicio 6

Calcula \(a\) y \(b\) sabiendo que

\[ \lim_{x \to 0} \frac{x\operatorname{sen}(x) + a(e^x - 1) + \operatorname{sen}(x)}{bx^2 + x - \operatorname{sen}(x)} = 1 \]

Cálculo de los parámetros \(a\) y \(b\)

1. Primera aplicación de la regla de L'Hôpital

Al sustituir \(x = 0\), tanto el numerador como el denominador valen \(0\), por lo que tenemos una indeterminación \(\left[\frac{0}{0}\right]\). Derivamos numerador y denominador:

\[ \lim_{x \to 0} \frac{x\operatorname{sen}(x) + a(e^x - 1) + \operatorname{sen}(x)}{bx^2 + x - \operatorname{sen}(x)} \stackrel{\text{L'H}}{=} \lim_{x \to 0} \frac{\operatorname{sen}(x) + x\cos(x) + ae^x + \cos(x)}{2bx + 1 - \cos(x)} \]

2. Imponemos que el límite sea finito para obtener \(\boldsymbol{a}\)

Al evaluar el nuevo límite en \(x = 0\), el denominador tiende a \(0 + 1 - 1 = 0\) y el numerador tiende a \(0 + 0 + a + 1 = a + 1\).

Para que el límite pueda ser finito (e igual a \(1\)), el numerador debe tender también a \(0\):

\[ a + 1 = 0 \implies \mathbf{a = -1} \]

3. Segunda aplicación de L'Hôpital para obtener \(\boldsymbol{b}\)

Sustituyendo \(a = -1\) volvemos a tener \(\left[\frac{0}{0}\right]\). Aplicamos L'Hôpital una segunda vez:

\[ \lim_{x \to 0} \frac{\operatorname{sen}(x) + x\cos(x) - e^x + \cos(x)}{2bx + 1 - \cos(x)} \stackrel{\text{L'H}}{=} \lim_{x \to 0} \frac{\cos(x) + \cos(x) - x\operatorname{sen}(x) - e^x - \operatorname{sen}(x)}{2b + \operatorname{sen}(x)} \]

Evaluamos en \(x = 0\): el numerador tiende a \(1 + 1 - 0 - 1 - 0 = 1\) y el denominador tiende a \(2b\). (Nótese que \(b\) no puede ser \(0\), pues daría límite infinito). Igualando el cociente a \(1\):

\[ \frac{1}{2b} = 1 \implies 2b = 1 \implies \mathbf{b = \frac{1}{2}} \]

Tendencia de \(h(x)\) cerca de \(x = 0\) para \(a = -1\) y \(b = \frac{1}{2}\): ambos límites laterales convergen a \(1\).

Solución final: Los parámetros pedidos son \(a = -1\) y \(b = \dfrac{1}{2}\).
